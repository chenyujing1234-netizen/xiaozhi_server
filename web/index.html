核心功能

不是翻译机，是你的语音学伴

语伴 LinkPal 基于 ESP32-S3 便携语音硬件，搭配自建 Python 服务端。中文走 ASR→LLM→TTS 全链路；英语走 Omni 端到端 S2S，直接纠正发音与语法。

🎙️

脱手机、低干扰

ESP32-S3 + 麦克风 + 喇叭 + 小屏，独立语音交互，适合学生与儿童场景，减少屏幕依赖。

🗣️

口语伴 SpeakPal

英语模式采用百炼 Omni Realtime 端到端语音，听你说、直接纠正，不是 ASR→翻译→TTS 流水线。

🔓

全栈开源可自建

固件、服务端、硬件方案全部开源。替换 OTA 地址即可连到你自己的服务器，智能体模式可扩展。

🤖

小智中文对话

默认小智模式：流式 ASR + 通义千问 + CosyVoice TTS，支持唤醒词、状态屏显与 MCP 设备控制。

🔄

OTA 切换智能体

同一硬件，改 OTA URL 即可切换小智 / 英语陪练，无需换板子。后续可扩展化学引导等更多模式。

🛠️

创客友好

面包板套件可快速上手；也可参考 LinkDog 生态做机器狗形态。BOM 透明，成本可控。

智能体模式

一个硬件，多种学伴

通过修改设备 OTA 地址切换模式。服务端已在本机部署，地址会根据当前域名自动显示。

小智助手

默认模式 · 中文对话

MQTT 1883 · UDP 8001

日常语音助手：问答、陪伴、设备控制。ASR → Qwen → CosyVoice 流式全链路。

  • 唤醒词「你好小智」
  • 屏幕状态：聆听 / 说话 / 思考
  • 错误语音提示 + 屏幕 alert

OTA 地址：
http://YOUR_HOST:8002/xiaozhi/ota/

口语伴 SpeakPal

英语陪练 · Omni S2S

MQTT 1884 · UDP 8003

英语口语纠正：音频直接进 Omni Realtime，音频直接出，低延迟、自然对话感。

  • 引导式学习，纠正发音与语法
  • 独立端口，不影响小智通道
  • 静音超时自动结束会话

SpeakPal 口语练习（网页版）：
https://linkpal.cloud/english/

OTA 地址：
http://YOUR_HOST:8002/xiaozhi/ota/english/

快速上手

四步连上你的语伴

设备与服务器需在同一网络（或公网可达），防火墙放行对应端口。

1

采购 & 组装

购买套件，按接线教程连接麦克风、功放、屏幕与按键。

2

烧录固件

从 Gitee 拉取固件，ESP-IDF 编译烧录，设置 OTA URL 指向本服务器。

3

启动服务端

python server.py，配置 PUBLIC_HOST 与 DASHSCOPE_API_KEY。

4

唤醒对话

说「你好小智」开始中文对话；切英语 OTA 即可练口语。
