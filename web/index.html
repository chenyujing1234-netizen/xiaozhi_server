核心功能

不是翻译机，是你的语音学伴

语伴 LinkPal 基于 ESP32-S3 便携语音硬件，搭配自建 Python 服务端。中文走 ASR→LLM→TTS 全链路；英语走 Omni 端到端 S2S，直接纠正发音与语法。

🎙️

脱手机、低干扰

快速上手

四步连上你的语伴

设备与服务器需在同一网络（或公网可达），防火墙放行对应端口。

1

采购 & 组装

购买套件，按接线教程连接麦克风、功放、屏幕与按键。

2

烧录固件

从 Gitee 拉取固件，ESP-IDF 编译烧录，设置 OTA URL 指向本服务器。

3

启动服务端

python server.py，配置 PUBLIC_HOST 与 DASHSCOPE_API_KEY。

4

唤醒对话

说「你好小智」开始中文对话；切英语 OTA 即可练口语。
